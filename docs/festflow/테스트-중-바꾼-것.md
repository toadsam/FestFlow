# 테스트하다 불편해서 바꾼 것

2026 가을축제 "바람"(10.07 ~ 10.08)을 앞두고, 직접 눌러 보면서 불편했던 점과 그래서 바꾼 것을 적어 두는 기록이다.
커밋 메시지는 "무엇을 바꿨는지"를 적고, 이 문서는 "왜 바꿨는지"를 적는다.

## 적는 법

- 테스트 중에 불편해서 바꾼 것이 생기면, 커밋할 때 이 문서 맨 위(가장 최근)에 한 칸을 추가한다.
- 한 칸에는 **불편했던 점 → 바꾼 것 → 커밋**을 적는다. 고민했지만 바꾸지 않은 것은 맨 아래 "바꾸지 않기로 한 것"에 이유와 함께 적는다.
- 암호 · 운영 키 · 계좌 같은 값은 적지 않는다(이 저장소는 공개다).

## 2026-10-02

### 자리 현황판 — 빈 자리로 바꿀 때 확인 창

- **불편했던 점**: 운영진 여럿이 각자 폰으로 현황판을 켜고 돌아다니며 자리를 체크하려고 한다. 그런데 "이용 중"인 테이블은 한 번만 눌러도 바로 빈 자리가 돼서, 잘못 누르면 손님이 앉아 있는 자리가 비워진다.
- **바꾼 것**: 이용 중 → 빈 자리로 바꿀 때 확인 창이 먼저 뜬다. 창에 지금 상태와 앉은 지 몇 분인지 보여 주고, "빈 자리로 바꾸기"를 눌러야 비워진다. 창을 띄워 둔 사이 다른 사람이 먼저 비웠으면 창을 닫고 알려 준다. 빈 자리 → 이용 중은 그대로 한 번에 된다.
- **같이 맞춘 것**: 현황판 안내 문구, 눌러 보는 운영 매뉴얼의 자리 비우기 단계, 운영 매뉴얼 본문.
- **커밋**: `98c3bcd`

- **바꾼 것**: Vercel 방문 통계(Web Analytics)를 연결했다. 운영 사이트에서만 세고, 로컬과 눌러 보는 운영 매뉴얼 안의 연습 화면은 세지 않는다.
- **알아 둘 것**: 무료 한도는 월 50,000건이고 넘어도 요금은 없다(수집만 멈춤). 보관은 30일이라 축제가 끝나면 한 달 안에 숫자를 따로 남겨야 한다.

## 바꾸지 않기로 한 것

### 영상 아래 "멈춤 · 크게 보기" 버튼 (2026-10-02)

- **고민한 점**: PC 에서 카드 안 영상을 멈추거나 크게 보는 방법이 안 보였다.
- **결론**: 넣지 않았다. 모바일에서는 유튜브 플레이어의 자체 버튼(영상을 한 번 누르면 나옴)으로 다 된다.

### 자리 현황판을 여럿이 동시에 쓸 때의 약점 (2026-10-02)

- **확인한 점**: 폰 화면이 꺼졌다 켜지면 옛날 상태가 그대로 보일 수 있다(주기적으로 다시 읽는 장치가 없다). 이미 비운 자리를 또 비우면 오류 문구가 뜬다. 이미 이용 중인 자리를 또 "이용 중"으로 누르면 앉은 시간이 처음부터 다시 센다. 빠르게 연달아 누르면 뒤의 것이 무시된다.
- **결론**: 축제 직전에 서버와 운영 화면을 건드리지 않기로 했다. 대신 확인 창을 넣었고(위 기록), 운영 규칙으로 막는다.
- **운영 규칙**: 폰을 다시 켰거나 한동안 안 봤으면, 누르기 전에 새로고침을 한 번 한다. 현황판 위쪽의 "갱신" 시각이 오래됐으면 새로고침한다.

### 총학생회 관리자와 소개팅 관리자의 암호 분리 (2026-10-02)

- **확인한 점**: 두 화면은 같은 관리자 계정으로 로그인한다. 암호는 서버 환경 변수로만 바꿀 수 있고, 앱 안에 바꾸는 화면은 없다.
- **결론**: 계정을 나누지 않고 그대로 쓴다. 따로 쓰려면 계정을 하나 더 만들 수 있게 코드를 고쳐야 한다.
