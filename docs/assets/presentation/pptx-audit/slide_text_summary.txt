[19] 기술 스택 및 구현 구조
     paragraphs=15 images=0 mediaRefs=0 hyperlinks=0
     - 기술 스택 및 구현 구조
     - FestFlow는 현대적인 웹 기술과 AI API를 결합하여 방문객·스태프·관리자 모두를 위한 통합 플랫폼을 구현했습니다.
     - FESTFLOW: AI 기반 대학교 축제 통합 운영 플랫폼
     - 프로젝트 요약
     - 시스템 개요
     - 기술 스택
     - 향후 개선
     - FRONTEND | REACT / VITE / TAILWIND / PWA
     - Spring Boot 기반 RESTful API 서버를 구축하고, MySQL과 JPA를 통해 데이터를 관리합니다. SSE(Server-Sent Events)를 활용하여 부스 상태 변경 및 공지사항이 방문객 화면에 실시간으로 반영됩니다.
     - BACKEND | SPRING BOOT / MYSQL / JPA
     - 인증 및 실시간 통신 | JWT / SSE
     - AI 기능 | OPENAI API 기반 챗봇 / 이미지 생성 / 운영 보조
     - React와 Vite를 기반으로 빠른 빌드 및 SPA 구조를 구현하였으며, Tailwind CSS로 반응형 UI를 설계했습니다. PWA 적용으로 모바일 환경에서도 앱처럼 사용 가능하며, 현장 접근성을 극대화했습니다.
     - OpenAI API를 활용하여 축제 챗봇, AI Match 프로필 이미지 생성, 공지 초안 자동 생성, 운영 브리핑 지원 등 다양한 AI 기능을 구현했습니다. 단순 챗봇을 넘어 운영 지원 도구로 확장된 AI 활용이 핵심입니다.
     - JWT 기반 인증으로 관리자·스태프·방문객 역할별 접근 권한을 분리 관리합니다. SSE를 통한 단방향 실시간 통신으로 서버 부하를 최소화하면서도 즉각적인 현장 정보 반영이 가능합니다.
