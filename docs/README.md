# FestFlow 문서 및 이미지 자산 구조

이 폴더는 발표/문서/검증용 자료를 모아두는 공간입니다.

## 폴더 구조

- `ai-match/`: AI Match 사용설명서, 관리자 설명서, 기술문서
- `festflow/`: FestFlow 전체/프론트엔드/백엔드/홈페이지 문서
- `assets/ai-match/`: AI Match 관리자 화면 이미지
- `assets/diagrams/`: 기술 아키텍처, UML, 흐름도 이미지
- `assets/presentation/`: PPT 검토 이미지, 역할 카드용 모바일 이미지
- `assets/qa-screenshots/`: QA 및 실제 화면 검증 스크린샷
- `assets/screenshots/admin/`: 관리자 화면 스크린샷
- `assets/screenshots/previews/`: 발표용 기능 미리보기 스크린샷

## 정리 기준

- 앱 실행에 직접 필요한 파일은 `frontend/`, `backend/`에 유지합니다.
- 발표와 문서에 쓰는 이미지/문서는 `docs/` 아래에 둡니다.
- 새 발표용 이미지를 만들면 `assets/presentation/` 아래에 기능별 폴더를 만들어 보관합니다.
